Composite 3D, Home, Help Mode, Carpet Configuration e XML Panel



1. Composite 3D → orientação visual das layers



- A representação visual das layers está invertida.



- Correção necessária:

  - As layers inferiores (sombra/projeção visual) devem aparecer deslocadas para sul-direita.

  - Atualmente a projeção está indo para norte-esquerda.



- Objetivo:

  - Tornar a leitura espacial intuitiva.

  - Deve ficar evidente que:

    - Z negativo representa uma layer superior.

    - Z positivo representa uma layer inferior.



- A visualização atual das camadas não deixa essa relação clara.

- Reforçar a percepção de profundidade através do posicionamento e empilhamento visual das layers.

4. Help Mode (novo recurso)



- Adicionar um novo botão ao lado de "Display Settings".



- Ícone:

  - Lupa



- Nome:

  - Help Mode



- Função:

  - Ativar/desativar sistema de ajuda contextual em todo o aplicativo.



Comportamento:



- Ao passar o mouse sobre:

  - botões

  - campos

  - títulos

  - labels

  - informações

  - seções



  deve aparecer uma caixa flutuante explicativa.



Estilo visual:



- Design minimalista.

- Fundo semitransparente.



- Se Dark Mode estiver ativo:

  - fundo preto translúcido.



- Se Dark Mode estiver desativado:

  - fundo amarelo translúcido.



Animações:



- Fade in suave ao aparecer.

- Fade out suave ao remover o mouse.



Exemplo:



- Em Borders → Direction Grid:

  - Ao passar o mouse sobre "N":

    - exibir "North"



  - Ao passar sobre "S":

    - exibir "South"



  - Ao passar sobre "E":

    - exibir "East"



  - Ao passar sobre "W":

    - exibir "West"



  - Aplicar o mesmo conceito para todas as siglas do sistema.



Objetivo:

- Tornar o editor mais acessível para novos usuários sem poluir a interface.

8. XML Panel → Expand XML Panel



- O comportamento atual está invertido.



Problema:



- Ao clicar em "Expand XML Panel", o painel está sendo deslocado para a esquerda (<).



Comportamento esperado:



- O painel XML deve expandir para a direita (>).



- O objetivo é:

  - liberar mais espaço para o painel central

  - manter uma experiência mais natural de redimensionamento



- O painel XML deve ocupar a extremidade direita da interface quando expandido.
