3. Walls → correção de XML output



- Problema atual:

  - Ao criar uma nova wall configuration:

    - server lookid aparece como 0 no input

    - porém NÃO está aparecendo no XML output por padrão. Deve aparecer a tag com valor 0 mesmo se não preenchido um id.



- Correção obrigatória:

  - sempre que server lookid for 0 (ou qualquer valor definido), deve ser incluído no XML



- Exemplo esperado:



  server_lookid="0"



- Regras:

  - se campo estiver vazio → usar 0

  - se campo tiver valor → usar valor informado

  - nunca omitir a tag server_lookid no XML quando existir configuração de wall
